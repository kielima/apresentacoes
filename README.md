# Apresentações — repositório aposentado

As apresentações que moravam aqui passaram, em agosto de 2026, para o repositório
do site: [github.com/kielima/kielima-site](https://github.com/kielima/kielima-site),
em `public/ppt/`. Elas são publicadas em **[kielima.com/ppt](https://kielima.com/ppt)**.

| Endereço antigo | Endereço novo |
|---|---|
| `kielima.github.io/apresentacoes` | [kielima.com/ppt](https://kielima.com/ppt) |
| `kielima.github.io/apresentacoes/dissertacao/` | [kielima.com/ppt/dissertacao](https://kielima.com/ppt/dissertacao) |

## Por que mudou

`kielima.github.io/apresentacoes` não era o site. Era um endereço à parte, que
ninguém alcançava a partir de `kielima.com` e que não dizia de quem era sem que
alguém explicasse. Agora as apresentações estão no domínio próprio, com link no
menu da home.

## Por que este repositório continua existindo

Pelos links já compartilhados. As duas páginas que sobraram aqui não são
apresentações: são redirecionamentos para os endereços novos, para que nada que
já foi enviado por e-mail, colado num slide ou anotado em algum lugar termine
num 404.

Não acrescentar apresentações aqui. O histórico anterior a esta mudança continua
no git, caso alguma coisa precise ser recuperada.
