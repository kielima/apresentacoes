# Repositório aposentado

As apresentações não moram mais aqui. Desde agosto de 2026 elas estão em
[github.com/kielima/kielima-site](https://github.com/kielima/kielima-site), na pasta
`public/ppt/`, publicadas em `kielima.com/ppt`.

O que sobrou neste repositório são duas páginas de redirecionamento, para que os
links antigos (`kielima.github.io/apresentacoes`) não terminem num 404.

## Se você veio aqui para mexer numa apresentação

Está no repositório errado. Vá para o `kielima-site` — e leia o `CLAUDE.md` de lá,
que é onde vive a regra de tipografia que antes vivia aqui:

> **Tamanho mínimo de texto: 24px.** Nunca criar nem alterar texto de uma
> apresentação para um tamanho de fonte inferior a 24px.

## Se você veio aqui para mexer neste repositório

Só há um motivo legítimo: o endereço de destino mudou e os redirecionamentos
precisam acompanhar. O CI trava qualquer outra coisa — ele confere que a lista de
arquivos não mudou e que as duas páginas continuam apontando para
`kielima.com/ppt`.

Não acrescentar apresentações aqui. Elas não seriam publicadas em lugar nenhum que
esteja divulgado.
